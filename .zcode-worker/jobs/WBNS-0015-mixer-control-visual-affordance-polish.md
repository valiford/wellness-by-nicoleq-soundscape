# WBNS-0015 — Mixer control visual affordance polish

STATUS: READY
AGENT: ZCODE
AUTOMATION_ELIGIBLE: true
PRIORITY: 3

## Goal
Refine the soundscape mixing controls so they look deliberate, premium, and easy to manipulate without changing the core product identity.

## Scope
- Improve slider thumb/track sizing, active/focus/hover states, value feedback, spacing, and alignment.
- Make the current value and mute state visually obvious without clutter.
- Improve touch targets while keeping the interface compact.
- Ensure dark/light/background contrast remains readable over the current visual treatment.
- Keep controls stable during interaction; no geometry changes that move the target under the pointer.

## Acceptance
- Sliders have clear idle/hover/focus/active/muted states.
- Touch targets meet practical mobile sizing without distorting the layout.
- Visual changes remain coherent at narrow, tablet, and desktop widths.
- Keyboard focus is visible and the UI remains usable at text/display zoom.

## Constraints
Preserve current branding and audio behavior. No wholesale redesign, deploy, or release. Finish in REVIEW.
